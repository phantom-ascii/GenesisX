# GenesisX

[![License: CERN-OHL-S-2.0](https://img.shields.io/badge/License-CERN--OHL--S--2.0-blue.svg)](LICENSE)

GenesisX is an open-source 2-in-1 laptop designed and built from scratch. It features a custom motherboard, 360° hinge, OLED touchscreen, detachable wireless keyboard, active pen support, and a focus on making a powerful, repairable Linux laptop without relying on an existing laptop platform.
